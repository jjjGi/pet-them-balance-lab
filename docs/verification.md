# 검증 기록

## 2026-09-16 — 실험실 분리와 MCP 서버 첫 동작

.NET SDK 10.0.400 / Windows 11 / Release 빌드.

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check.ps1
~~~

### 자동으로 확인한 항목

검사 **9개 통과**, 빌드 경고 0 / 오류 0.

1. 출력 경로가 `experiments/` 밖을 가리키면 거부한다. 상위 경로 탈출과 절대 경로 모두 막힌다.
2. 등록된 봇 정책 3종이 모두 끝까지 실행되고, 없는 정책 ID는 거부된다.
3. 같은 시드·정책은 같은 결과를 만들고, 다른 시드는 다른 결과를 만든다.
4. 요약의 집계값이 실행별 결과와 일치한다. 별도로 계산해 대조했다.
5. 실행 횟수(1–200)와 시뮬레이션 길이(최대 3600초) 한도가 실행 전에 적용된다.
6. 기록된 JSONL의 `kill` 이벤트 수·종료 처치 수·피해량·스냅샷 개수가 실행기가 보고한 값과 일치한다.
7. 잘린 기록은 `complete: false`로 표시되고 사망으로 해석되지 않는다. 헤더 없는 파일과 깨진 JSON 줄도 경고로 남는다.
8. 손상된 설정과 빈 설정은 거부된다.
9. **MCP 서버를 실제 자식 프로세스로 띄워** `initialize` → `tools/list` → `tools/call`을 주고받고, 도구 5개가 모두 노출되며, 경로 탈출 호출이 거부되는 것을 확인했다.

9번은 빌드 성공이 아니라 실제 프로토콜 통신을 확인한다.

### 시뮬레이터 이관이 동작을 바꾸지 않았음

게임 저장소의 기존 시뮬레이터와 이 저장소의 시뮬레이터를 시드 42–46으로 각각 실행하고
`run_start` 줄(실행 ID와 타임스탬프 성격의 값 포함)을 제외한 이벤트 스트림을 SHA-256으로 비교했다.

| 시드 | 이벤트 수 | 결과 |
| --- | --- | --- |
| 42 | 1681 | 동일 |
| 43 | 1692 | 동일 |
| 44 | 1676 | 동일 |
| 45 | 1668 | 동일 |
| 46 | 1695 | 동일 |

처치 수(154/154/149/144/155)도 게임 저장소의 기존 검증 표와 일치한다.
로그 파일 이름만 `orbit-bot-<seed>`에서 `orbit-auto-punch-v1-<seed>`로 바뀌었다. 정책을 이름에 드러내기 위한 변경이다.

### 밸런스 측정 결과: 현재 설정은 봇 기준으로 위험이 없다

시드 42–46, 180초, 기본 설정 `prototype-0.1`.

| 정책 | 승리 | 처치(평균) | 받은 피해 | 남은 체력 |
| --- | --- | --- | --- | --- |
| `orbit-auto-punch-v1` | 5/5 | 151.2 | 0 | 100 |
| `still-auto-punch-v1` | 5/5 | 237.6 | 0 | 100 |
| `flee-auto-punch-v1` | 5/5 | 239.2 | 0 | 100 |

**제자리에 서서 펀치만 반복하는 봇도 단 한 번도 맞지 않는다.**
게임 저장소의 기존 기록은 "회피하는 봇이 피해 없이 생존할 수 있다"고 적었는데, 실제로는 회피조차 필요 없다.
펀치 사거리(2.6 + 판정 여유)와 쿨다운(0.38초) 대비 피해량(26)이 커서, 적이 접촉 거리(0.75)에 닿기 전에 죽는다.

움직이는 봇이 오히려 처치 수가 적은 것은, 이동하면 적과 멀어져 펀치 판정에 덜 들어오기 때문이다.

이것은 **관찰된 결과**다. 원인 가설과 수정 후보는 아직 검증하지 않았다.
사람이 실제로 조작해 본 뒤에 수치를 바꾼다. 봇이 쉽다는 이유만으로 난이도를 올리지 않는다.

### 구현 중 확인한 사항

MCP stdio 서버에 요청을 모두 쓴 직후 stdin을 닫으면, 서버가 응답을 쓰기 전에 전송 계층이 종료되어
stdout이 비어 버린다. 실제 클라이언트처럼 응답을 받은 뒤에 stdin을 닫아야 한다.
검사 9번은 이 순서를 지킨다.

### 아직 확인하지 않은 항목

- 실제 AI 클라이언트(Claude Code, Codex 등)에 등록해서 자연어 요청으로 도구를 호출하는 전체 흐름.
- Windows 외 운영체제.
- 사람의 플레이 기록 읽기. 기록이 아직 0건이라 실행해 볼 수 없다.
- `compare_experiments`, `analyze_playtests`, `create_balance_candidate`, `Create_Balance_Report`: 미구현.
- 대용량 기록(수십 MB)에서의 읽기 성능.
